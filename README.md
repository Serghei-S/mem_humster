# Hamster Mirror

Локальный сервис, который берет кадр с веб-камеры и показывает, какой из хомяков ближе всего к вашему текущему выражению лица.

## Как это работает

- Браузер получает изображение с камеры.
- На клиенте скрыто анализируется геометрия лица: рот, глаза, брови и асимметрия.
- Бэкенд сравнивает эти признаки с профилями хомяков и добирает контекст визуальным и текстовым сходством.
- На странице есть хомякометр, блок "что вижу на лице" и лента последних попаданий.

Никакого дообучения на хомяках здесь нет: используются готовые модели и сравнение по близости.

## Структура

- Код приложения лежит в корне проекта.
- Картинки хомяков лежат в `data/hamsters`.
- Фронтенд лежит в `static`.

## Запуск

```powershell
py -m pip install -r requirements.txt
py -m uvicorn app:app --reload
```

После старта откройте [http://127.0.0.1:8000](http://127.0.0.1:8000) и разрешите доступ к камере.

## Что важно знать

- На первом запуске `transformers` скачает модель `openai/clip-vit-base-patch32` из Hugging Face.
- Для анализа лица в браузере используется локальная модель `MediaPipe`, лежащая в `static/models/face_landmarker.task`.
- Если геометрию лица не удалось считать, сервис временно переключается на fallback по общему кадру.
- Чтобы сменить набор хомяков, достаточно заменить картинки в `data/hamsters`.
