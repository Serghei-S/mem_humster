# Hamster Mirror

Локальный сервис, который берет кадр с веб-камеры и показывает, какой из хомяков в папке проекта сейчас ближе всего к вашему выражению лица.

## Как это работает

- Браузер получает изображение с камеры.
- Бэкенд вырезает лицо из кадра.
- `CLIP` строит zero-shot профиль выражения по богатому набору текстовых признаков.
- Для каждого хомяка используется не только его картинка, но и отдельное подробное словесное описание.
- Кадр пользователя сравнивается и с визуальными эмбеддингами, и с текстовыми описаниями хомяков.
- На странице есть хомякометр и лента последних попаданий, чтобы смотреть, как образ меняется вживую.

Никакого дообучения на хомяках здесь нет: используются готовые эмбеддинги и сравнение по близости.

## Запуск

```powershell
py -m pip install -r requirements.txt
py -m uvicorn app:app --reload
```

После старта откройте [http://127.0.0.1:8000](http://127.0.0.1:8000) и разрешите доступ к камере.

## Что важно знать

- На первом запуске `transformers` скачает модель `openai/clip-vit-base-patch32` из Hugging Face.
- Если лицо не находится, сервис берет центральную часть кадра.
- Чтобы сменить набор хомяков, достаточно заменить картинки в корне проекта.
